# 構文と値

Stacker のプログラムは、空白で区切られた **トークン** の並びです。このページでは、数値・文字列・リスト・コードブロックなどの値をどう書くか、コメントをどう書くか、そして値にどんな型があるかを説明します。名前（変数や関数）の書き方は [名前とシンボル](names-and-symbols.md) にまとめています。

## トークンと空白

Stacker は左から右へトークンを 1 つずつ読み、次の規則で処理します。

- 数値や文字列などの **値** は、スタックに積まれる
- **演算子**（`+`、`dup` など）は、スタックの上から必要な個数の値を取り出し、結果を積む

演算子は値の **後ろ** に書きます（RPN、逆ポーランド記法）。

```
stacker:0> 1 2 +
[3]
stacker:1> 3 *
[9]
```

`1 2 +` は「1 を積む、2 を積む、`+` が上の 2 つを足す」という意味で、括弧も優先順位も要りません。2 行目の `3 *` は、スタックに残っていた 3 に対して続きを実行します。

トークンの区切りは空白だけです。空白を省くと、つながった文字列全体が 1 つのトークンになります。

```text
1 2+
UndefinedSymbolError: `2+` is not defined.
```

`2+` という名前のトークンとして読まれ、そんな名前は定義されていないのでエラーになります。演算子の前後は必ず空白を空けてください。空白の数は何個でも同じ意味です。

```
stacker:0> 1    2   +
[3]
```

## 数値

- 整数: 10 進数。先頭に `+` / `-` を付けられる（`42`、`-7`、`+5`）
- 浮動小数: 小数点を含む（`3.14`、`.5`、`1.`）
- 指数表記: `e` / `E` の後ろに指数（`1e3`、`1.5e-2`）。結果は浮動小数
- 16 進数: `0x` で始める（`0xff`）
- 2 進数: `0b` で始める（`0b101`）
- 8 進数: `0o` で始める（`0o17`）
- 複素数: 実部と虚部を空白なしでつなぎ、虚部の末尾に `j`（`1+2j`、`3j`）

```
stacker:0> 42
[42]
stacker:1> 3.14
[42 3.14]
stacker:2> 1e3
[42 3.14 1000.0]
stacker:3> 0xff
[42 3.14 1000.0 255]
stacker:4> 0b101
[42 3.14 1000.0 255 5]
stacker:5> 0o17
[42 3.14 1000.0 255 5 15]
stacker:6> -0xff
[42 3.14 1000.0 255 5 15 -255]
```

`1e3` は整数ではなく浮動小数（`1000.0`）になります。16 / 2 / 8 進数は整数として積まれ、`0xFF` のように大文字でも書けます。桁区切りにアンダースコアを使えます（`1_000` は `1000`）。

複素数は `1+2j` のように **空白なしで** 書きます。虚部の単位は `j`（`J` も可）で、`i` は使えません。空白を入れると別々のトークンになり、`+` は足し算の演算子として読まれます。

```
stacker:0> 1+2j
[(1+2j)]
stacker:1> 3-1j *
[(5+5j)]
stacker:2> 2j
[(5+5j) 2j]
```

2 行目では、スタックにある `(1+2j)` と `3-1j` を掛けています。

## 文字列

文字列は `"..."` か `'...'` で囲みます。2 つの書き方に違いはなく、中に `"` を含めたいときは `'` で囲み、`'` を含めたいときは `"` で囲みます。

```
stacker:0> "Hello, World!"
['Hello, World!']
stacker:1> 'say "hi"'
['Hello, World!' 'say "hi"']
stacker:2> "it's"
['Hello, World!' 'say "hi"' 'it's']
```

スタックの表示では、文字列は常に `'...'` で囲まれます。表示の囲みは値の一部ではありません。`echo` で出力すると囲みなしで表示されます。

```
stacker:0> "Hello, World!" echo
Hello, World!
[]
```

文字列は `+` で連結できます。

```
stacker:0> "x" "y" +
['xy']
```

### 複数行の文字列

三重クォート（`"""..."""` または `'''...'''`）で囲むと、改行を含む文字列を 1 つのトークンとして書けます。三重クォートの中には `"` や `'` をそのまま書けます。

```
stacker:0> """line1
... > line2""" echo
line1
line2
[]
stacker:1> '''say "hi"''' echo
say "hi"
[]
```

REPL では、閉じていないクォートや括弧があると、入力が次の行に続きます（上の `... >` の行です）。

### エスケープは解釈されない

文字列の中の `\n` や `\t` は **改行やタブにならず**、バックスラッシュと文字がそのまま入ります。

```
stacker:0> "a\nb" echo
a\nb
[]
stacker:1> "a\nb" len
[4]
```

改行を含めたいときは、上の三重クォートを使います。`\"` と書くと文字列はそこで終わらずに続きますが、バックスラッシュも文字列に残ります（`"a\"b"` の長さは 4 です）。引用符を含めたいときは、囲む側の引用符を変える方法を使ってください。

文字列の中では `#` もコメントの開始になりません。`"a#b"` は `a#b` という文字列です。

## リスト

リストは `[` と `]` で囲み、要素を **空白で** 区切ります。

```
stacker:0> [1 2 3]
[[1 2 3]]
stacker:1> [1 [2 3] [4 [5]]]
[[1 2 3] [1 [2 3] [4 [5]]]]
```

外側の `[ ]` はスタック全体の表示、内側がリスト 1 つです。リストは入れ子にできます。要素に書けるのは、数値・文字列・`true` / `false` / `null`・リスト・名前（変数の値になる）で、演算子は書けません（`[1 2 +]` はエラーです）。ブロックも書けません。ブロックを要素にしたいときは `{1 2 +} 1 listn` のようにスタックから作ります。

### 行列と区切りの `;`

`;` を使うと、行ごとのリストを要素にしたリスト、つまり行列を書けます。

```
stacker:0> [1 2 3; 4 5 6]
[[[1 2 3] [4 5 6]]]
stacker:1> [1 2 3; 4 5 6] len
[[[1 2 3] [4 5 6]] 2]
```

`;` を境に 1 行分が 1 つのリストになります。`;` のあとで改行しても構いません。`;` のない `[1 2 3` の改行は、ただの空白と同じ扱いです。

### カンマ区切りはエラー

他の言語に慣れていると `[1, 2, 3]` と書きたくなりますが、Stacker ではエラーになります。

```text
[1, 2, 3]
StackerSyntaxError: Commas are not used in Stacker arrays; separate elements with spaces: [1 2 3]
```

## コードブロック

`{...}` で囲んだ部分は **コードブロック**（ブロック）です。ブロックは **評価されずに** スタックに積まれ、`eval` などの語が実行を指示したときに初めて走ります。

```
stacker:0> {1 2 +}
[{1 2 +}]
stacker:1> eval
[3]
```

`if`、`times`、`do` などの制御構造は、条件や本体をブロックで受け取ります。関数の定義（`defun`、`lambda`）も、引数と本体をブロックで渡します。それぞれの詳細は [制御構文](control.md) と [関数・ラムダ・マクロ](functions-and-macros.md) を参照してください。

ブロックの扱いで押さえておくことが 2 つあります。

- 算術演算子や `echo` など多くの演算子は、引数にブロックを渡されると、ブロックを評価した結果を使います（`{1 2 +} 3 *` は `9`）。評価せずに保存したいときは、`set` や `defun` のようにブロックを評価しない語に渡します（[名前とシンボル](names-and-symbols.md#ブロックを束縛すると評価せずに保存される) を参照）。
- 名前 1 つだけを入れた `{x}` は、「その名前そのもの」を表す特別な書き方でもあります。詳細は [名前とシンボル](names-and-symbols.md) を参照してください。

## true / false / null

`true`、`false`、`null` は、名前ではなく **値** を書くリテラルです。変数や関数のように参照されるのではなく、数値と同じようにそのままスタックに積まれます。

```
stacker:0> true
[true]
stacker:1> false
[true false]
stacker:2> null
[true false null]
```

`null` は「値がない」ことを表す値です。

リテラルなので名前としては使えず、再定義もできません。`set` の名前の位置に書くとエラーです。

```text
5 true set
StackerSyntaxError: `set` expects a name, got True
```

`true` と `false` の型は `bool` です。`bool` は整数の一種として振る舞い、`true 1 ==` は `true`、`1 true +` は `2` になります。

## コメント

`#` から行末まではコメントで、無視されます。

```
stacker:0> 1 2 + # これはコメント
[3]
```

`#|` と `|#` で囲んだ範囲はブロックコメントです。複数行にまたがれて、式の途中にも書けます。ブロックコメントは入れ子にできます。

```
stacker:0> 1 #| 途中のコメント |# 2
[1 2]
stacker:1> #| 外側 #| 内側 |# まだ外側 |# 3
[1 2 3]
```

## 値の型

スタックに積まれる値の型は次のとおりです。

| 型 | 書き方の例 |
| --- | --- |
| int | `42`、`0xff` |
| float | `3.14`、`1e3` |
| complex | `1+2j` |
| str | `"abc"`、`'abc'` |
| list | `[1 2 3]` |
| ブロック | `{1 2 +}` |
| Symbol | `:x` |
| bool | `true`、`false` |
| None | `null` |

`type` はこの型を Python のクラスとして返します（`1 type` は `<class 'int'>`、`null type` は `<class 'NoneType'>`）。

- 文字列リテラルの値は `str` を継承した `String` 型です。`type` や `str?` からは `str` として見えるので、普段は区別する必要がありません。
- ブロックは `type` などの演算子に渡すと評価されてしまうため、`type` でブロックの型を調べることはできません。
- Symbol は名前そのものを表す値です。詳しくは [名前とシンボル](names-and-symbols.md) を参照してください。
- `lambda` で作る無名関数も値の一種で、`λa.{a}` のように表示されます。

型の確認には `int?`、`float?`、`complex?`、`str?`、`list?`、`bool?`、`number?`、`symbol?`、`null?` を使います。`int?` と `number?` は `bool` に対して `false` を返します。

```
stacker:0> 1 int?
[true]
stacker:1> "a" str?
[true true]
```

変換には `int`、`float`、`complex`、`str` などの語があります。型の判定・変換を行う語の一覧は [演算子リファレンス](operators.md) を参照してください。
