# 配列と辞書

リスト `[1 2 3]` は値で、中身を書き換える語はありません。`cons` や `sorted` はいつも新しいリストを返します。要素をその場で書き換えたいとき、キーで値を引きたいときは、配列と辞書を使います。配列と辞書を書き換える語は、名前が `!` で終わります。

## 配列

`[1 2 3] array` でリストから配列を作ります。文字列やコードブロックからも作れます（`list` が受けるものと同じ）。長さと中身から作るには `n x array-of` と書きます。

```
stacker:0> [1 2 3] array :a set
[]
stacker:1> 9 a 0 at!
[]
stacker:2> 4 a append!
[]
stacker:3> a
[[9 2 3 4]]
stacker:4> a pop!
[[9 2 3] 4]
stacker:5> clear 3 0 array-of
[[0 0 0]]
```

| 語 | 書き方 | 動作 |
|---|---|---|
| `array` | `xs array` | xs の要素を持つ新しい配列。1 段だけ変換する（`[[1 2] [3 4]] array` の中はリストのまま） |
| `array-of` | `n x array-of` | 長さ n、どの要素も x の新しい配列 |
| `at` | `c i at` | c の i 番目。c は取り去る。リスト・文字列・ブロックにも使える（`nth` は c を残す） |
| `at!` | `v a i at!` | a の i 番目を v にする。何も積まない。範囲外はエラー（配列は伸びない） |
| `slice` | `a i j slice` | i 番目から j 番目の手前までを**新しい配列**で積む。a は取り去る。リスト・文字列にも使える |
| `append!` | `v a append!` | a の末尾に v を足す |
| `pop!` | `a pop!` | a の末尾の要素を取り除いて積む。空ならエラー |

書き込む語の引数は「値 → 場所 → 語」の順で、`set`（`3 :x set`）と同じです。読む語は「場所 → 語」です。添字は 0 始まりで、負の添字は末尾から数えます。

## 辞書

`dict` で空の辞書を作ります。キーは文字列・数値・シンボルです（`true` / `null` / リスト / 配列はキーにできません）。文字列 `"a"` とシンボル `:a` は別のキー、`1` と `1.0` は同じキーです。

```
stacker:0> dict :d set
[]
stacker:1> 1 d "a" put!  2 d :b put!
[]
stacker:2> d
[{'a' 1 b 2}]
stacker:3> d "a" get  d "z" get  d :b has?
[{'a' 1 b 2} 1 null true]
stacker:4> clear d keys
[['a' b]]
```

| 語 | 書き方 | 動作 |
|---|---|---|
| `dict` | `dict` | 空の新しい辞書 |
| `get` | `d k get` | k の値。なければ `null` |
| `put!` | `v d k put!` | k の値を v にする。なければ足す。既にあるキーの順番は変わらない |
| `has?` | `d k has?` | k があるか |
| `del!` | `d k del!` | k を取り除く。なければエラー |
| `keys` / `values` | `d keys` | キー / 値のリスト（入れた順）。呼んだ時点の中身から作るので、あとで辞書を書き換えても変わらない |

値として `null` を入れたのか、キーが無いのかは `has?` で区別します。

## 1 つの実体

配列と辞書は、どこへ渡しても同じ 1 つの実体です。`dup`、変数、関数の引数、リストの要素、ブロックへの差し込み（`sub`）のどれを通っても、コピーされません。どこから書き換えても、どこからも見えます。

```
stacker:0> [1 2] array :a set  a dup  7 swap 1 at!
[[1 7]]
stacker:1> clear [a 1] :p set  9 a 0 at!  p
[[[9 7] 1]]
```

2 次元の表は、行ごとに配列を作ります。`array-of` に配列を渡すと、すべての行が同じ 1 つの配列になってしまうので、エラーになります。

```
stacker:0> 0 2 seq {drop 3 0 array-of} map array :g set
[]
stacker:1> 5 g 1 at 2 at!  g
[[[0 0 0] [0 0 5] [0 0 0]]]
```

## 等しいか、同じか

`==` は中身を比べます。同じ中身のリストと配列も等しくなります。同じ実体かどうかは `same?` で調べます。木やリストのノードを辞書で表して、ノードどうしを比べるときは `same?` を使ってください（中身の比較は、親や前後へのポインタで循環します）。

```
stacker:0> [1 2] array [1 2] array ==  [1 2] array [1 2] ==  [1 2] array dup same?  [1 2] array [1 2] array same?
[true true true false]
```

自分自身を含む配列どうしの `==` はエラーになります。

## 既存の語との関係

読むだけの語（`len` `nth` `dolist` `map` `filter` `reduce` `sorted` `reversed` `sum` `cdr` `contains` `expand` …）は、配列をリストと同じように受け取ります。新しい並びを返す語（`map` `sorted` `cdr` …）が返すのは**リスト**です。配列に戻すには `array` を付けます。`dolist` や `map` は、始めた時点の要素を回します。本体で同じ配列に `append!` しても、回る回数は変わりません。

辞書は列ではありません。`dolist` / `map` / `sorted` / `sum` / `list` などに渡すとエラーになります。`keys` や `values` のリストを回してください。`len` は辞書のキーの数を返します。

`list?` は配列に `false`、`array?` と `dict?` がそれぞれ `true` です。`empty?` は空の配列にも `true` です（`null?` は `null` にだけ `true`）。

## 表示

配列はリストと同じ `[1 2 3]` の形で表示されます。REPL のスタック表示では配列に専用の色が付くので見分けられます。色の無い場所（`echo`、`str`、ファイルへの出力）ではリストと区別が付かないので、確かめたいときは `array?` を使います。辞書は `{'a' 1 b 2}` と、キーと値を入れた順に並べて表示されます（ブロックの表示と同じ括弧ですが、辞書のリテラルはありません）。自分自身を含む配列・辞書は、その場所が `[...]` / `{...}` になります。入れ子が深すぎるときも同じです。

表示を入力に貼り直すと、配列の表示はリストのリテラルとして読まれます。元の配列には戻りません。
